# 서울, 너와 함께 검색 노출(SEO · AEO · GEO) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 홈(`/`)이 검색 결과 · 공유 카드 · AI 검색에서 이 앱이 무엇인지 제대로 소개되게 하고, Vercel 미리보기는 색인되지 않게 한다.

**Architecture:** 운영 주소 · 앱 이름 · 설명 · 미리보기 판정 · 메타 조립을 `src/utils/seo.ts` 한 곳에 둔다. 메타데이터는 한국어 고정이다([ADR 0005](../../adr/0005-client-side-i18n-metadata-stays-korean.md) 유지). 공유 이미지는 `public/og.png` 를 메타에 직접 넣는다(Next 파일 규칙 이미지는 페이지가 openGraph 를 따로 정의하면 사라진다 — 상황실 작업에서 확인). JSON-LD 는 서버 컴포넌트인 `src/app/page.tsx` 가 `<script type="application/ld+json">` 으로 넣는다.

**Tech Stack:** Next.js 16.2.6(lockfile 기준, App Router), React 18.3, TypeScript(`@ts-nocheck` 파일 다수), Vitest(jsdom), ESLint 9, Prettier, react-i18next.

**Spec:** 포트폴리오 저장소의 `docs/superpowers/specs/2026-11-20-seo-aeo-geo-design.md` §2 · §4.6 · §4.7 · §5

## 조사 결과 (2026-11-26)

- 운영 `https://date-eight-navy.vercel.app` 의 `/robots.txt` · `/sitemap.xml` · `/llms.txt` 모두 404. canonical · 공유 카드 · JSON-LD 없음. 설명은 `서울에서 즐기는 데이트, 식사 그 모든 계획을 한 번에!`.
- **`/statistics` 는 공개 페이지가 아니다.** `src/app/statistics/page.tsx` 가 `redirect('/')` 하고 운영도 307 → `/`. 설계 §4.6 은 공개로 적었지만 사이트맵에서 뺀다.
- 운영 Lighthouse 13.4.1 모바일 SEO 기준선: `/` 100, `/statistics`(→ `/`) 100. → "점수를 올렸다"고 쓰지 않는다.
- 화면에 보이는 값(기본 언어 한국어, `src/i18n/locales/ko.json`): 앱 이름 `서울, 너와 함께`, 위치 동의 안내 `서울, 너와 함께는 현재 계신 곳을 중심으로 맞춤형 날씨와 데이트 장소를 추천해 드려요! … (본 서비스는 서울 지역 한정으로 제공됩니다.)`, `오늘 추천 데이트 장소`, `추천식당 리스트 Top 5`, `선택하신 지역의 날씨 정보입니다.`, `지역 선택`, 언어 토글 `KO · EN · JA · ZH`, 푸터 `Copyright © 2026 BYUN SEJUN.`
- 언어는 URL 이 아니라 화면 안에서 바뀐다(클라이언트 i18n, ADR 0005). 서버 렌더와 첫 화면은 항상 한국어.
- `node_modules` 가 2024 년 것(설치된 next 13.5.6)이고 lockfile 은 16.2.6 이다 → 먼저 `npm ci`.
- `src/proxy.js` 는 `/api/:path*` 에만 걸린다(CORS). 새 경로에 영향 없음.
- 공유 이미지 후보: `docs/images/01-hero.png`(1920×928, README 첫 그림).
- ADR 은 `docs/adr/NNNN-*.md`(영문 제목 + 한국어 본문, Status/Date/Context/Decision/Rationale/Consequences), README `## ADR Index` 에 목록. 지금 목록에 0005 가 빠져 있다.
- 커밋 형식: `type(scope): 한국어 제목` (예: `fix(layout): …`, `docs(readme): …`). husky + lint-staged(prettier · eslint --fix).

## Global Constraints

- 구조화 데이터 · 메타에는 화면에 보이는 값만 쓴다(위 "조사 결과"). 메타는 한국어 고정(ADR 0005).
- 언어별 주소(hreflang)는 만들지 않는다(설계 §2 — 언어별 URL 이 없다).
- 새 클라이언트 JS 금지. 새 `'use client'` 파일 없음. JSON-LD 는 서버 컴포넌트가 HTML 에 넣는다.
- 정본 주소는 상수 `SITE_URL = "https://date-eight-navy.vercel.app"`. 미리보기에서도 canonical 은 운영을 가리킨다.
- 미리보기 판정은 `VERCEL_ENV === "preview"` 만. 그때만 루트 `robots: { index: false, follow: false }` 와 robots.txt `Disallow: /`. 로컬 · 운영은 색인.
- 운영 robots 는 `/api/` 만 막는다. AI 검색 로봇은 따로 막지 않는다.
- 레이아웃 `openGraph` 는 이 앱에 페이지가 사실상 하나라 루트에 전체를 둔다. 단 `/statistics` 의 기존 metadata 는 redirect 페이지라 건드리지 않는다.
- 게이트: `npm run lint`, `npx tsc --noEmit`(기존에 통과하던 상태면 유지), `npm test`, `npm run build`. Next 빌드가 SecurityFatalError(업그레이드 권고)로 멈추면 한 번만 다시 돌린다. Next 업그레이드 금지. API 키가 필요한 화면 동작은 확인 대상이 아니다.
- 커밋: `feat(seo): …` / `docs(adr): …` / `docs(readme): …` + 한국어 제목, 본문 2~5줄(왜 · 무엇을 확인했는지), 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 면접관이 읽는 글이라 사람이 쓴 문체로. `--no-verify` 금지(husky 가 prettier 를 돌린다).
- 공개 문서에 저장소 밖 경로를 쓰지 않는다. 구글 리치 결과 테스트는 자동화하지 못하니 "했다"고 쓰지 않는다.
